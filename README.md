# КУРС — курсы валют ЦБ РФ

Pet-проект: React-интерфейс с графиком дневных курсов Банка России и Symfony API. Данные запрашиваются напрямую из XML API ЦБ РФ; приложение не использует биржевые котировки или свечи.



## Запуск в VS Code Dev Container

1. Откройте репозиторий в VS Code и выполните **Dev Containers: Reopen in Container**.
2. При первом создании контейнера автоматически устанавливаются PHP/Composer- и Node-зависимости, а фронтенд собирается в `frontend/dist`.
3. Откройте `http://localhost:8081` на компьютере, где работает Docker. Nginx раздаёт собранный интерфейс и передаёт `/api/*` Symfony.

Если Docker запущен на удалённом компьютере, используйте порт `nginx:80`, который VS Code пересылает локально. Порт `5173` доступен для режима разработки.

### Разработка интерфейса

В терминале Dev Container:

```bash
npm --prefix frontend run dev -- --host 0.0.0.0
```

Откройте `http://localhost:5173`. Vite проксирует API-запросы в Nginx внутри Docker-сети.

После изменений фронтенда пересоберите production-версию, чтобы увидеть их на странице Nginx:

```bash
npm --prefix frontend run build
```

### Быстрая проверка API

```bash
curl 'http://localhost:8081/api/cbr/rates'
```

Ответ содержит валюту и массив дневных значений `{ "time": "YYYY-MM-DD", "value": число }`. По умолчанию возвращается история за последний год. Поддерживаются валюты USD, EUR, GBP и CNY к RUB; диапазон — не более пяти лет. Для изменения периода передайте параметры `from`, `to` и `currency` (например, `?currency=R01235&from=2025-01-01&to=2025-02-01`).

## Временный публичный доступ через ngrok

Туннель делает приложение доступным по публичному URL, пока ngrok запущен. Перед демонстрацией соберите фронтенд и убедитесь, что локальная страница и API отвечают:

```bash
npm --prefix frontend run build
curl -I http://localhost:8081/
curl 'http://localhost:8081/api/cbr/rates'
```

Установите и авторизуйте ngrok на компьютере, где доступен локальный порт приложения, следуя [официальной инструкции ngrok](https://ngrok.com/docs/getting-started/). Затем запустите туннель только к веб-приложению:

```bash
ngrok http 8081
```

Откройте HTTPS-адрес, который покажет ngrok, и используйте его для демонстрации. Если Dev Container работает удалённо, пересылайте `nginx:80` в VS Code и запускайте ngrok на локальный порт, указанный VS Code для этой пересылки, например `ngrok http <локальный-порт>`.

Не создавайте туннели к PostgreSQL или pgAdmin и не публикуйте конфигурационные файлы с секретами. После демонстрации остановите ngrok: адрес будет доступен публично только на время работающего туннеля.

## Сбросьте переменные окружения перед запуском. Выполните запуск ngrok с очисткой прокси-переменных для текущей сессии:• Linux / macOS:bash

```bash
unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY all_proxy ALL_PROXY

```
